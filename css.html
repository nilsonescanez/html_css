CSS

CSS (Cascading Style Sheets) é a Linguagem usada para definir a aparencia e o layout das páginas feita com HTML, controlando cores, fontes, espaçamentos, tamanhos e posicionamento dos elementos; em resumo, emqunto o HTML estrutura o conteudo, o CSS deixa tudo visualmente organizado e bonito.
